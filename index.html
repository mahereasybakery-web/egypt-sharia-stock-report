تثبيت التطبيق على سطح الجوال

للوصول السريع والتشغيل الفوري كأي تطبيق أصلي

🍏 لمستخدمي آيفون (iPhone / Safari):
  1. اضغط على زر المشاركة [ 📤 Share ] في شريط المتصفح بالأسفل.
  2. مرر للأسفل واختر [ ➕ إضافة إلى الصفحة الرئيسية / Add to Home Screen ].
  3. اضغط على [ إضافة / Add ] في الزاوية العلوية ليظهر التطبيق على شاشة هاتفك مباشرة.
🤖 لمستخدمي أندرويد (Android / Chrome):
  1. اضغط على زر [تثبيت الآن] أدناه أو زر خيارات المتصفح (الثلاث نقاط ⋮).
  2. اختر [تثبيت التطبيق / Install App].
  3. سيتم إنشاء أيقونة التطبيق تلقائياً على شاشة هاتفك الرئيسية.
